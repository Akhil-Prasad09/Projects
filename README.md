# Projects

Smaller personal projects.

## [Green Basket](Green%20Basket)

A React demo of a marketplace for handcrafted products by rural Indian women artisans: product and artisan listings, a seller dashboard with an add-product form, an admin approval panel and a mock UPI/Razorpay checkout. All data is mock data in the app. [Live demo](https://akhil-prasad09.github.io/Projects/). See the [folder README](Green%20Basket/README.md) to run it.
